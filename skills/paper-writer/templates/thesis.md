# 硕士学位论文写作指南

## 适用范围

硕士学位论文。面向社科类（经济学、管理学、公共管理、社会学等），其他学科可参考结构部分。

---

## 论文构成

学位论文完整构成（按装订顺序）：

```
封面 / 扉页
声明（原创性及知识产权）
中文摘要 + 关键词
英文摘要 + Keywords
目录
正文（含前言/导论）
参考文献
附录（可选）
后记
致谢
在读期间科研成果目录
```

---

## 摘要

- 中文摘要约 1000 字，不加注释和评论的简短陈述
- 内容应包含：论文主要内容与观点、主要贡献（创新之处）
- 不能照搬提纲或作为目录的细化
- 关键词 3-8 个，另起一行排在摘要下方
- 英文摘要可在中文摘要基础上缩写

---

## 前言（导论/绪论）

前言是正文的一部分，应包含：

1. **研究问题的意义**：为什么这个问题值得研究
2. **相关领域前人工作与知识空白**：文献综述（可放在前言中或独立成章）
3. **理论工具和研究方法**：概述方法论选择
4. **基本思路和逻辑结构**：全文的论证路线
5. **其他需要交代的问题**

注意：言简意赅，不要与摘要雷同，不要成为摘要的注释。

---

## 正文

### 写作原则

- 使用论说文体，包含论点、论据、结论
- 一篇论文只有一个中心，层层展开
- 对不同观点进行评价、驳论，不是简单介绍
- 提出自己的新观点，不能"述而不作"
- 正文字数不少于 30000 字（工学类不少于 25000 字）

### 章节结构

正文章节结构不固定——由论文的研究类型决定。常见组织方式：

**实证研究型**：
```
前言 → 文献综述 → 理论分析与假设 → 研究设计 → 实证结果 → 结论
```

**案例研究型**：
```
前言 → 文献综述 → 理论框架 → 案例描述 → 案例分析 → 讨论与结论
```

**规范研究型**：
```
前言 → 文献综述 → 理论建构 → 模型推导 → 政策分析 → 结论
```

**混合方法型**：
```
前言 → 文献综述 → 研究设计 → 质性分析 → 量化验证 → 综合讨论 → 结论
```

paper-writer 根据用户的研究计划书和实际内容动态生成章节文件。

## 注释与参考文献

### 注释

- 采用**脚注**格式
- 直接引用的文字、数据、事实资料需注释
- 转述他人观点也应注释出处
- 格式：
  - 刊物：作者、篇名、刊物名、出版年号、期号
  - 著作：作者、著作名、出版单位、出版年号、页号

### 参考文献

- 列示直接利用的或有直接帮助和启发作用的文献
- 包括著作、论文、统计资料、工作报告等
- 外文著作、论文应以原文列出
- 格式与注释一致

---

## 结论

- 概括论文的主要发现和核心观点
- 政策建议要具体可操作
- 研究局限诚实陈述
- 未来研究方向 1-2 条

---

## 写作顺序建议

1. 研究设计 / 方法论（最确定的部分先写）
2. 分析章节（实证/案例/理论推导）
3. 文献综述
4. 前言/导论
5. 结论
6. 摘要（最后写）

---

## 注意事项

- 学位论文的 LaTeX/Word 排版模板由学校提供或从 `templates/presets/` 选择
- 如果学校有指定模板，将其放入 `templates/custom/`
- 答辩前建议用 integrity-auditor 做全面检查（引用验证 + 数字一致性）
- 查重率要求因学校而异，通常 < 15%
