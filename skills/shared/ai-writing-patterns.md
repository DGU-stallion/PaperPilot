# AI 写作模式检测清单

> Single source of truth。`paper-writer` 和 `integrity-auditor` 均引用此文件。
> paper-writer 用于**预防**（写作时避开）；integrity-auditor 用于**诊断**（提交前发现）。

---

## 中文论文

| 模式 | 典型表现 | 正向替换方向 |
|------|---------|------------|
| 过度破折号 | "——这表明——" 连接长句 | 用句号分句 |
| 万能过渡词 | "值得注意的是""不难发现""由此可见" | 直接陈述结论 |
| 对仗堆砌 | "一方面…另一方面…" 反复出现 | 减少对仗，直述逻辑 |
| 空泛修饰 | "显著""重要""深远""深刻" 密集出现 | 用具体数据替代 |
| 万能结尾 | "为…提供了新的视角/思路/借鉴" | 写出具体启示内容 |
| 万能开头 | "近年来，随着…的发展…" | 第一句切入研究问题 |
| 不必要中英混杂 | 有公认中文译法的术语仍用英文 | 有中文译法时用中文 |
| 总结过多 | 每段结尾"由此可见…" | 只在章节关键处总结 |

## 英文论文

| 模式 | 典型表现 | 正向替换方向 |
|------|---------|------------|
| 过度对冲 | "might" "could" "potentially" 密集堆砌 | 有根据的陈述用 will/is |
| 万能过渡 | "It is worth noting that…" "Notably," 反复出现 | 直接进入内容 |
| 过度破折号 | Em dash 过度使用 | 用句号或逗号 |
| 模板化贡献 | "This study contributes to the literature by…" | 具体说贡献是什么 |
| 句式重复 | 连续 3 句以上用同一句式结构 | 变换句式 |

---

## 严重程度分级

| 级别 | 标准 | integrity-auditor 处理方式 |
|------|------|--------------------------|
| 轻微 | 偶发（全文 ≤3 处） | 建议改善，不阻塞投稿 |
| 中等 | 某一模式出现 4-8 次 | 建议修正，列出具体位置 |
| 明显 | 某一模式出现 >8 次，或多种模式叠加 | 必须修正后再投稿 |
