# Literature Review

## 职责边界

**所需信息**：一份文献清单（带摘要/关键词）。  
**产出**：`literature/literature_review.md`（成文综述，可直接用于论文）。  
**完成标准**：综述按主题组织，覆盖趋势/争议/空白/核心论文四要素，每节末明确本研究的定位，无逐篇罗列。  
**不做**：文献搜索和引用验证（→ paper-search）；数据搜集（→ data-collector）。

---

## Step 1 — 收集所需信息

查找顺序：
1. 读取 `papers/<project>/literature/paper_search.md`（paper-search 的产出）
2. 读取用户在对话中提供的文献列表（BibTeX、手写列表、PDF 目录均可）
3. 读取 `papers/<project>/topics/research_proposal.md`，了解研究问题和理论框架
4. 仍无文献清单时，向用户追问："你有已收集好的文献列表吗？可以粘贴标题列表或上传 .bib 文件。"

向用户确认综述范围：

```
"文献清单已就绪（[N] 篇）。开始写综述前确认：

  1. 综述用途：论文中的文献综述节 / 独立综述论文
  2. 篇幅要求：[如有]
  3. 目标读者对该领域的熟悉程度：[专家 / 一般学术读者]

没有特殊要求的话，按标准结构来。"
```

**完成标准**：文献清单已加载，研究问题已知，综述用途和篇幅已确认。

---

## Step 2 — 精读与要素提炼

对清单中每篇文献（核心论文精读，其余摘要级别），提炼以下五要素：

| 要素 | 说明 | 追问 |
|------|------|------|
| **趋势与模式** | 理论、方法或结论随时间的演变 | 某些方法是否越来越流行或被淘汰？ |
| **核心主题** | 文献中反复出现的问题或概念 | 哪些概念在不同论文中都被讨论？ |
| **争议与矛盾** | 研究者之间的分歧 | 对同一问题有何不同立场？ |
| **里程碑论文** | 改变该领域方向的奠基性研究 | 哪篇论文之后该领域发生了明显转向？ |
| **空白与不足** | 现有研究缺失的环节或局限性 | 什么问题还没有被回答？ |

提炼完成后，向用户展示初步地图：

```
"文献地图初稿：
  主要主题：[X, Y, Z]
  核心争议：[...]
  识别到的空白：[...]
  本研究填补的空白：[...]

你觉得这个地图准确吗？有没有遗漏的重要维度？"
```

**完成标准**：五要素已覆盖清单中所有核心论文，文献地图已经用户确认。

---

## Step 3 — 规划结构

四种组织方式，可单独使用或组合：

| 结构 | 适用场景 | 注意 |
|------|---------|------|
| **主题式**（推荐） | 大多数社科论文 | 每节围绕一个概念/争议，不是一篇论文 |
| **时间顺序** | 追踪理论演进 | 避免变成流水账，每个时期要有判断，解释为什么某个转折点会发生 |
| **方法论** | 方法比较综述 | 明确每种方法的适用条件和局限 |
| **理论流派** | 存在明显学派分野 | 点明流派之间的根本分歧 |

这四种结构可以组合：例如整体按主题划分各节，每节内部按时间顺序讨论该主题的演进。选定结构后说明组合方式。

规划完成后输出大纲让用户确认：

```
拟定结构：
  2.1 [主题A] — 覆盖 [X] 篇
  2.2 [主题B] — 覆盖 [Y] 篇
  2.3 研究空白与本文定位

确认后开始写作。
```

**完成标准**：结构已规划，大纲已经用户确认。

---

## Step 4 — 写作

### 引言

引言完成两件事，顺序固定：

1. 说明综述的范围和焦点（覆盖哪些方面，不覆盖什么）
2. 预告结构（"本综述分三个主题展开……"）

不从宏观背景或领域历史开头。

### 正文各节

按确认的结构逐节撰写，每段写作遵循四条原则：

| 原则 | 做法 | 反面 |
|------|------|------|
| **综合，不罗列** | 同一段用多篇文献支撑同一论点 | 一篇文献独占一段 |
| **解释，不转述** | 论点后加"这意味着……"或"这说明……" | 只改写摘要内容 |
| **批判性评估** | 必要时指出研究局限（样本、方法、情境）| 只说"该研究发现……" |
| **段落有主题句** | 每段首句说明本段论点，段间用过渡词衔接 | 段落无明确论点，只是素材堆积 |

每节额外要点：
- 开段：说明本节主题和覆盖范围（1句），不用"本节将介绍..."
- 收尾：指出本主题的局限，引向下一节或研究空白

### 结论

结论完成两件事：

1. 总结从文献整体中得出的主要发现——是跨文献的综合判断，不是每篇论文的摘要
2. 明确这些发现对本研究的意义：本研究如何填补上述空白，或在此基础上推进

不以"综上所述"开头。以"因此，本研究……"或"基于上述空白……"收尾。

写作全程主动避开 `skills/shared/ai-writing-patterns.md` 中列出的高频 AI 写作模式。

**完成标准**：引言/正文/结论三部分均已完成；每段有多篇文献支撑同一论点（无单篇独占段落）；每节末有本研究定位的关联；结论有跨文献综合判断，不是逐篇摘要；无 TODO 占位符。

```markdown
...

## 三、研究空白与本文定位
现有研究在以下方面存在不足：
1. [空白1] — 已有研究 [...] 但尚未 [...]

```

## 质量 Checklist

- [ ] 引言明确了综述范围和结构，未从宏观背景开头
- [ ] 按主题组织，每段有多篇文献支撑同一论点（无单篇独占段落）
- [ ] 每段有主题句，段间有过渡词
- [ ] 有解释和批判性评估，不只是转述
- [ ] 五要素（趋势/主题/争议/里程碑/空白）均有体现
- [ ] 每节末有本研究定位的关联说明
- [ ] 结论有跨文献的综合判断，不是逐篇摘要，以本研究收尾
- [ ] 所有引用来自 `paper_search.md` 或用户提供的清单（无新增未验证引用）
- [ ] 无 AI 套话（"综上所述"、"值得注意的是"等）
- [ ] 篇幅符合用户要求
