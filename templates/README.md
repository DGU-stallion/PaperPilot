# PaperPilot 论文项目模板

这是 PaperPilot 创建新论文项目时使用的目录结构模板。

## 项目结构

```
your-paper/
├── topics/           <- 选题研究、研究提案
├── literature/       <- 文献综述和参考文献
├── data/
│   ├── raw/          <- 原始数据
│   ├── clean/        <- 清洗后数据
│   └── scripts/      <- 数据处理脚本
├── analysis/
│   └── output/       <- 分析结果（表格、图表）
└── paper/            <- 论文源文件和编译输出
```

## 使用方式

这些模板文件会在 PaperPilot 创建新项目时自动复制。你不需要手动操作此目录。

如果你想开始一个新论文项目，请告诉你的 Coding Agent：

> 我想开始一篇新论文

Agent 会引导你完成项目创建和初始化。
